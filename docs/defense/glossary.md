# Термины простыми словами
| Термин | Значение в проекте |
|---|---|
| Контекст | Область с собственными правилами и смыслом данных |
| Микросервис | Независимое приложение, владеющее своей областью и данными |
| C4 Container | Уровень приложений/хранилищ, не обязательно Docker |
| Инвариант | Правило, которое нельзя нарушать при сбое |
| Saga | Последовательность локальных операций с действиями для исправления отказа |
| Оркестратор | Rental, который помнит шаги и отправляет команды |
| Компенсация | Новая операция, исправляющая эффект предыдущей: снять холд |
| Холд | Блокировка суммы на карте, ещё не окончательное списание |
| Идемпотентность | Повтор той же операции не создаёт дополнительного эффекта |
| Outbox | Исходящие сообщения в той же транзакции, что бизнес-изменение |
| Inbox | Учёт уже обработанных сообщений |
| At-least-once | Сообщение может прийти повторно |
| Eventual consistency | Сервисы согласуют состояние не мгновенно |
| Команда | Просьба выполнить действие: HoldDeposit |
| Событие | Сообщение о результате: DepositHeld |
| Correlation ID | Идентификатор всей аренды для связи сообщений |
| Operation ID | Идентификатор одного логического действия |
| Fencing epoch | Возрастающий номер выделения, отсекающий старые команды |
| Tombstone | Запись о закрытии, запрещающая запоздалое повторное создание |
| DLQ | Очередь проблемных сообщений для разбора, не решение бизнес-сбоя |
| ADR | Запись выбора с альтернативами и последствиями |
| ACL | В карте контекстов: адаптер, защищающий модель от чужого API; в безопасности: права доступа |
| 202 Accepted | Запрос принят, итог ещё не известен |
| UNKNOWN | Эффект мог произойти; требуется проверка |
