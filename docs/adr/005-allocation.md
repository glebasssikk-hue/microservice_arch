# ADR-005. Исключительное выделение автомобиля без слепого TTL
Статус: принято. Дата: 09.11.2026.

## Контекст
Два пользователя одновременно выбирают машину. Сервис доступа может ответить после таймаута. TTL способен освободить уже открытый автомобиль.

## Варианты
Проверить доступность в Rental; Redis-lock с TTL; уникальное выделение Fleet с явным закрытием.

## Решение
Fleet — единственный владелец allocation. Транзакционная блокировка строки и уникальность открытого выделения. Rental владеет уникальностью незавершённой аренды пользователя. Освобождение после подтверждённой компенсации; epoch увеличивается при новом выделении.

## Последствия
Плюсы: устойчивость к конкурентным запросам и поздним командам; не нужен распределённый lock. Минусы: зависшие выделения снижают доступность, нужен мониторинг. Нельзя освобождать исключительно по истечению 60 с.

## Когда пересмотреть
Можно добавить lease только после доказанного end-to-end fencing на всех устройствах; в текущей версии это лишняя сложность.
