# C4 — уровень Container
[Исходник Mermaid](containers.mmd). Использована обычная Mermaid flowchart с явными C4-типами, границей системы, ответственностью и технологиями. Container в C4 означает приложение или хранилище, а не обязательно Docker-контейнер.

Клиент — web SPA; четыре приложения сервисов — предполагаемый Java 21 / Spring Boot, базы PostgreSQL, брокер RabbitMQ. Это выбор для будущей реализации, а не существующее развёртывание. Один PostgreSQL-сервер допустим в учебном окружении, но базы и права различны.

На стрелках HTTP находятся операции OpenAPI; межсервисные команды и события проходят через RabbitMQ и описаны AsyncAPI. Брокер логически один, промышленная установка предполагает отказоустойчивую конфигурацию. Реплики/узлы не изображены, поскольку это не deployment diagram. UI оператора можно реализовать позже; сейчас ручное разбирательство описано процедурой в reliability.md.
